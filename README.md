# RoomLED

Единое управление подсветкой ПК: поиск устройств, группы, режимы, сцены («Новый год» и свои),
смена обоев Wallpaper Engine. Интерфейс открывается в браузере, всё работает локально.

Железо опрашивается через OpenRGB SDK (OpenRGB стоит рядом и работает в фоне).

## Запуск на Windows

1. Установи [Python 3.11+](https://www.python.org/downloads/) (галочка *Add to PATH*) и OpenRGB.
2. В OpenRGB: вкладка **SDK Server → Start Server** (или оставь запуск из RoomLED).
3. Закрой ASRock Polychrome Sync и любой другой софт для подсветки.
4. Дважды щёлкни `run.bat` (при первом запуске поставит зависимости).

Проверка без железа: `python -m roomled --demo`.

## Что умеет

- Зоны: плата, разъёмы ARGB, клавиатуры; выбор по одной, группами, «все вместе».
- Режимы: один цвет/чередование, дыхание, радуга, гирлянда, мерцание (случайные вспышки
  только из выбранных цветов), плавная волна.
- **Порядок каналов** у каждой зоны: если красный горит зелёным, выбери GRB.
- Сцены: набор режимов по группам + обои. Правый клик по сцене — удалить.
- Настройки и сцены хранятся в `%APPDATA%\RoomLED\config.json`
  (там же пути к OpenRGB и Wallpaper Engine).
